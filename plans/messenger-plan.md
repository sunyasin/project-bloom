# План создания Messenger.tsx

## Цель
Создать файл `src/pages/Messenger.tsx` на основе `src/pages/MessagesPage.tsx` с полной копией логики и функционала.

## Анализ MessagesPage.tsx

### Структура компонента

#### Imports (строки 1-28)
- React хуки: useState, useRef, useCallback, useEffect
- react-router-dom: useNavigate
- Кастомные хуки: useCurrentUserWithRole, useToast
- UI компоненты: MainLayout, Button, Input
- Иконки из lucide-react
- Типы: MessageWithSender, MessageTypeFilter, DeleteMessageConfirm, ConversationThread
- Константы: MESSAGE_TYPE_LABELS
- Утилиты: extractImageUrls
- Supabase клиент

#### Основные функции и логика

##### 1. Загрузка сообщений - loadMessages()
- Загружает сообщения из таблицы `messages` где пользователь является отправителем или получателем
- Загружает профили всех участников переписки
- Формирует объекты MessageWithSender с именами отправителей

##### 2. Группировка сообщений - getConversationThreads()
- Фильтрует удалённые сообщения
- Группирует по собеседнику (partnerId)
- Создает цепочки ответов на основе поля `reply_to`
- Сортирует по дате последнего сообщения

##### 3. Отправка ответа - handleSendReply()
- Создаёт новое сообщение с типом "chat"
- Привязывает к исходному сообщению через `reply_to`
- Обновляет список сообщений

##### 4. Удаление сообщений - handleDeleteMessages()
- Помечает сообщения как "deleted" (软删除)
- Не удаляет физически из БД

##### 5. Отметка прочитанным - markThreadAsRead()
- Помечает все непрочитанные сообщения в цепочке как прочитанные
- Автоматический таймер на 3 секунды

##### 6. Одобрение запроса койнов - handleApproveCoinRequest()
- Помечает сообщение как прочитанное

#### UI компоненты

##### Filter tabs
- Кнопки-вкладки для фильтрации по типу сообщения
- Показывают счётчик непрочитанных

##### Thread list
- Список бесед с собеседниками
- Превью последнего сообщения
- Бейджи типа сообщения

##### Expanded thread view
- Цепочки сообщений
- Ответы на конкретные сообщения
- Кнопки действий (ответить, удалить)
